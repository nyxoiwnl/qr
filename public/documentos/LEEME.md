# 📂 Carpeta de Documentos PDF

Coloca aquí tus archivos PDF con exactamente estos nombres:

- `documento-1.pdf`
- `documento-2.pdf`

> ⚠️ NO cambies los nombres de los archivos una vez que hayas generado los QR,
> ya que la URL quedaría rota.

## URLs públicas en producción

```
https://TU-PROYECTO.vercel.app/documentos/documento-1.pdf
https://TU-PROYECTO.vercel.app/documentos/documento-2.pdf
```

## URLs en desarrollo local

```
http://localhost:3000/documentos/documento-1.pdf
http://localhost:3000/documentos/documento-2.pdf
```
